# Changelog

## 1.0.0

- **Primeira versão do PokeWGGrid**, derivado do [IdleGrid](https://github.com/SamuelRomani/IdleGrid): mesmo organizador de contas, apontado pro `pokewg.com` em vez de outro jogo.
  *First version of PokeWGGrid, derived from IdleGrid: the same account organizer, pointed at `pokewg.com` instead of another game.*
- **Limite de 2 contas** (era 4 no IdleGrid) — 1 ou 2 painéis, escolhidos no menu.
  *2-account limit (IdleGrid had 4) — 1 or 2 panels, chosen from the menu.*
- **Sem as automações de jogo do IdleGrid.** O IdleGrid tem toggles opcionais (aceitar convite de party, fechar diálogo perdido, painel de Resumo lendo o HUD) que dependem de seletores específicos daquele outro jogo — removidos aqui de propósito: nada além de organizar sessões e fazer login automático.
  *No game automations from IdleGrid. IdleGrid has a few optional toggles (accept party invite, close stray dialog, a Resumo panel reading the HUD) that depend on that other game's specific selectors — removed here on purpose: nothing beyond organizing sessions and auto-login.*
- **Mantido do IdleGrid**: login automático, modo Eco, alertas de queda, backup/restauração de configuração, versão visível + atualização com um clique (código-fonte via `git pull`/ZIP, `.exe` via troca de binário), bandeja, iniciar com o Windows, três idiomas.
  *Kept from IdleGrid: auto-login, Eco mode, drop alerts, settings backup/restore, visible version + one-click update (source via git pull/ZIP, .exe via binary swap), tray, start with Windows, three languages.*
